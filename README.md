# Compound Interest Calculator Core

Independent Phase 1B TypeScript calculation core governed by Phase 1A Revision 4.

## Scope

- deterministic compound-interest engine;
- input validation and ordered assumption warnings;
- monthly ledger and ledger-derived annual schedule;
- strict versioned query parsing and canonical serialization;
- pure amount formatting boundary;
- independent reference-based tests.

UI, analytics, advertising, CMP, authentication, database work, publication and
deployment are outside Phase 1B.

## Commands

```bash
npm test
npm run typecheck
npm run build
npm run test:coverage
```
